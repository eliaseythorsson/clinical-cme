# International is the default guideline region; older ledgers keep theirs

The skill is to be installed by physicians anywhere, so a default of Iceland/Europe (Icelandic national guidance, then the European societies) would key a stranger's rounds to another country's rules. Since issue #56 the default region, and what a skipped answer at setup means, is **International**: items are keyed to the major European and US societies, an item never turns on a point where they disagree materially, the key accepts what either recommends, and the feedback names both with the difference (`standards.md` rule 2.1). A region in the learner's own words is read as written. The default blueprint's decision points no longer cite Icelandic statutes; they cite the national law on the point, which the checker reads for the learner's region.

An existing learner must not change region silently. Their region was explicit in every ledger written since `init` existed, but a ledger without one (missing, null or blank: a hand edit, an old page) read as Iceland/Europe. The load step (ADR 0003, issue #83) gets a named upgrade step, `old_default_region`: a ledger whose engine stamp is absent or not newer than `REGION_OLD_DEFAULT_UNTIL` (6.0.0, the last version with the old default) and that holds no region gets "Iceland/Europe" written into it, stored at the next write. `init` writes the default into a new ledger whenever the answer was skipped, so the step never mistakes a new learner for an old one, even before the version is bumped.

Not treated as Iceland-specific, so unchanged: SI laboratory units (the international standard) and blood gases in mmHg (the default in the US and most of Europe; kPa on request). The guideline-check seed (ADR 0011) applies to Iceland/Europe and International, both keyed to the European societies' guidelines the default blueprint cites.
